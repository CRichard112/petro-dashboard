Refresh Data

Click Run Refresh below. A terminal window will open, re-extract all prices from your Excel file, rebuild the dashboard, then open it fresh automatically.

Run Refresh
Refresh is a desktop-only action

You are viewing this dashboard online (GitHub Pages). The Refresh pipeline runs on your Windows PC and cannot be triggered from a web browser.

To refresh the data, on your PC:

  1. Open C:\Petro Prices\dashboard\ in Explorer
  2. Double-click refresh_and_relaunch.bat
  3. Wait ~60 seconds — a new dashboard tab opens automatically
  4. The online version updates within a minute after that
Refresh is running in the terminal window. When it completes, the dashboard will open automatically in a new tab. You can close this tab once the new one opens.

Upload Price Data

Add new data to any product series. Uploaded data is stored locally in your browser and layered on top of the master data from the Excel file.

1. Choose source / provider
2. Choose product
3. Upload CSV file

Required columns: date, price_avg — Optional: price_low, price_high, incoterm

Date format: YYYY-MM-DD or DD-Mon-YY (e.g. 12-Jun-26). Price unit should match existing series ($/bbl for crude, $/MT for all others).
